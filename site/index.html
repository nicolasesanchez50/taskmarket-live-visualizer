How to read this, and what is deliberately missing

  • Every figure is either copied verbatim from api.taskmarket.dev or arithmetic on those responses. Nothing is estimated, extrapolated or invented.
  • Reward volumes arrive in base units (6 decimals) and are divided by 1,000,000 here. Settlement counts are the API's own settlements field.
  • Poster counts are distinct requester addresses from the task list, not identities — no wallet is ever named or guessed, in line with the brief.
  • Both chains are shown, but the API currently returns identical market/breakdown/time-series figures for chain 4217 and 8453; only the task lists and activity feeds differ. That is reported as it is rather than papered over.
  • No wallet connection, no cookies, no analytics, no third-party scripts, no tracking of any kind. The page is static; the only network call it makes is for its own data.json.
